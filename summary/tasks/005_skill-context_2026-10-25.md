# 005 · Сделать `om_context_pack` выжимкой, а `om_read_skill` — срезом

**Дата:** 2026-10-25 · **Штамп:** skill-context · **Аудит:** [A005](../audit/005_skill-context_2026-10-25.md)

## Цель
Внешний агент читает нужный скилл в нужный момент и не переполняет контекст.

## Что сделать
1. `om_context_pack(pipeline, stage)` возвращает **только структуру**:
   цель стадии, `success_criteria[]`, `review_focus[]`, флаг `human_approval_default`,
   список доступных тулов, индекс скиллов (путь + размер + краткое описание).
   Ориентир — до **4 КБ**.
2. `om_read_skill(path, section?, max_chars=12000)`:
   `section` — поиск по markdown-заголовкам; `max_chars` — жёсткое усечение;
   по умолчанию — первые строки + оглавление файла.
3. `om_layer3_skills(tool)` — список путей Layer 3 + краткие описания;
   чтение — только через `om_read_skill`.
4. Правило «прочти Layer 3 перед вызовом тула» сохраняется как проверка по факту:
   мост возвращает пути и агенту — прочитать их перед `om_tool_run`.

## Готово, когда
- [ ] ответ `om_context_pack` ≤ ~4 КБ — тест
- [ ] `om_read_skill` никогда не превышает `max_chars` — тест
- [ ] директорский скилл читается целиком по `section` по требованию — тест
