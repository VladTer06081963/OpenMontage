## Реализованная поверхность (11 тулов, все read-only)

`om_preflight` · `om_pipelines` · `om_pipeline_manifest` · `om_project_state` ·
`om_checkpoint_read` · `om_artifact_read` · `om_board_state` · `om_tool_list` ·
`om_tool_info` · `om_read_skill` · `om_context_pack`

Контракт ответа: `{"ok": true, ...}` для dict-результатов и `{"ok": true, "items": [...]}`
для списков; ошибки — `{"ok": false, "error": ..., "error_type": ...}`.

## Реализованные защиты

- **Пути**: `project_id` — только slug; `artifact_read` не выходит за `projects/<id>/`;
  `read_skill` читает только `skills/`, `.agents/skills/`, `docs/`, `AGENT_GUIDE.md`
  (`.env` и `tools/*.py` — отказ).
- **Поверхность**: тест фиксирует, что в мосте нет ни одной write/execute-точки.
- **Гейт**: `write_checkpoint` для гейтовой стадии без апрува по-прежнему бросает
  `CheckpointValidationError` — проверено тестом.
- **Контекст**: `om_context_pack` — выжимка ≤ 4 КБ (фактически 1.3 КБ на стадию),
  полный текст — только через `om_read_skill(path, section, max_chars)`.
